# Problem Statement

## Problem

Managing library books and members manually can be time-consuming and may lead to errors in maintaining library records.

## Scope

The Smart Library Management System provides a simple Java-based solution for managing library members and books. It supports basic library operations such as adding books, searching books, issuing books, returning books, and displaying member details.

## Target Users

- Library members
- Librarians
- Library administrators

## High-Level Features

- Member registration
- Member category management
- Book management
- Book search
- Book issue and return
- Member details display
- Library information management
- Error handling
