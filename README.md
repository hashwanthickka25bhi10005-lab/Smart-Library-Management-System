# Smart Library Management System

## Overview

Smart Library Management System is a Java-based application designed to manage basic library operations. It allows users to interact with the library system, view member details, add books, search for books, issue/return books, and display library information.

## Features

- User/member registration
- Member category display
- Add books to the library
- Search books by title
- Issue books
- Return books
- Display user/member details
- Display database structure
- Menu-driven console interface
- Basic error handling

## Technologies / Tools Used

- Java
- Java Collections
- Object-Oriented Programming (OOP)
- Visual Studio Code
- Git
- GitHub

## Project Structure

The project consists of the following Java classes:

1. Book.java
   - Manages book details and book-related operations.

2. User.java
   - Stores basic user information.

3. Member.java
   - Manages library member details.

4. Librarian.java
   - Manages librarian information and operations.

5. Library.java
   - Handles library operations such as adding, searching, issuing, and returning books.

6. DatabaseManager.java
   - Handles database-related operations.

7. LibraryException.java
   - Provides custom exception handling for library operations.

8. Main.java
   - Contains the main method and provides the menu-driven interface.

9. README.md
   - Contains project documentation and information.

10. statement.md
    - Contains the project statement and requirements
## How to Install and Run

### Requirements

- Java JDK installed
- Visual Studio Code or any Java-compatible IDE
- Git/GitHub for version control

### Steps

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Make sure Java JDK is installed and configured.
4. Compile the Java source files.
5. Run the Main class.
6. Follow the menu displayed in the console.

## Testing

The application can be tested by:

1. Running the program.
2. Entering valid user details.
3. Adding books.
4. Searching for books by title.
5. Issuing and returning books.
6. Checking member details.
7. Testing invalid menu choices and input values.
8. Verifying that appropriate error messages are displayed.
